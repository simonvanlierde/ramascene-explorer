RaMa-Scene scenario explorer

How would the 2011 world economy's greenhouse-gas emissions, employment and metal-ore extraction change if Europe bought fewer cars, or if industries used less steel, cement or another material per unit of output? Each view is one precomputed run of the RaMa-Scene input-output engine on EXIOBASE. None of it is a forecast.

How to read this page

The engine changes final demand or technical coefficients in the 2011 economy and recomputes it. It has no projection step, and no substitution, price or rebound effect is modelled. There are three original interventions, plus a material-efficiency grid: ten products × five continental regions × three cut sizes, each cell "every industry in the region uses that much less of the product per unit of output".

EXIOBASE
A global multi-regional input-output database: what each industry in each region buys from every other, with the emissions, employment and extraction of each industry. Here version 3.3.sm, 49 regions.
RaMa-Scene
The engine that scales the selected cells of the economy and recomputes every region's totals through the Leontief inverse.
Technical coefficient
How much of a product an industry buys per unit of its own output.
Baseline
The unchanged 2011 economy. Every number on the page is an intervention minus this baseline.

Verification

    Full provenance

    Run a custom scenario

    One intervention on the 2011 base year, sent to the job API named in the page address and computed by the RaMa-Scene engine while you wait (about a minute; one job runs at a time). The result is compared with the baseline computed in the same job.

    Provenance (live job)

    No precomputed data here yet. The page reads data/results.json (with data/regions.json for the map and data/flows.json for the Sankey), which only a run of the engine on the EXIOBASE dataset produces:

    uv run python precompute.py --run --engine ../ramascene-pr2 --data "$DATASETS_DIR" \
    --out data/results.json --out-regions data/regions.json --out-flows data/flows.json

    To check the page itself, open it with ?data=tests/fixture.json (synthetic, bannered).
